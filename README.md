## 🚀 The Problem

Creating content is easy.

Creating content that **performs** is not.

Creators and marketers often publish content based on intuition:

> "I think this post will perform well."

But by the time the analytics arrive, it is already too late.

Traditional social media analytics primarily tell you:

**What happened?**

Viralyze focuses on a more valuable question:

> **What is likely to happen — and how can we improve the content before publishing?**

🎯 Core Problem

Creating content is often treated like gambling:

Create → Post → Hope

Viralyze aims to replace that workflow with:

Analyze → Predict → Optimize → Publish → Measure

The goal is not to guarantee virality.

Virality depends on many external variables, including:

- Timing
- Distribution
- Audience
- Platform algorithms
- Competition
- Account history
- Current events
- Market conditions
- Luck

Therefore, Viralyze treats its prediction as an estimated content-performance potential, not a guarantee.

🔐 Security

Security is a core requirement.

Viralyze should implement:

- Secure authentication
- Password hashing
- Secure session/JWT handling
- Rate limiting
- API authentication
- Input validation
- CSRF protection where applicable
- Secure environment variables
- Database access controls
- File upload validation
- Abuse prevention
- Proper authorization checks

Important

AI provider API keys must never be exposed to the frontend.

All sensitive credentials should remain server-side and be managed through environment variables or a secure secrets-management system.

# ⚡ Getting Started

## Prerequisites

Make sure you have:

- Node.js 18+
- npm
- Git

---

## 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Viralyze.git
cd Viralyze
```

> Replace `YOUR-USERNAME` with your GitHub username.

---

## 2. Install Dependencies

```bash
npm install
```

---

## 3. Configure Environment Variables

Create a `.env.local` file in the project root.

```env
DATABASE_URL=file:./db/custom.db

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=

NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
```

Add any additional AI/API credentials required by your deployment.

### ⚠️ Important

Never commit secrets to GitHub.

Do not expose:

```text
.env
.env.local
API keys
OAuth secrets
Database credentials
Service role keys
```

---

## 4. Run the Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
